# Bom de Pau — fachada inicial do ARG

Site institucional fictício da madeireira Bom de Pau, criado para uma campanha de RPG.

## Estrutura
- `index.html`: página inicial e conteúdo institucional.
- `css/style.css`: visual responsivo.
- `js/main.js`: menu mobile.
- A área de registro gráfico contém uma mensagem cifrada de exemplo para o primeiro enigma.

## Testar localmente
Abra `index.html` no navegador. As fontes e fotografias usam links externos, então precisam de conexão com a internet.

## Publicar no GitHub Pages
1. Crie um repositório chamado `bom-de-pau-arg`.
2. Envie os arquivos e pastas mantendo a estrutura.
3. Abra **Settings → Pages**.
4. Em *Build and deployment*, escolha **Deploy from a branch**.
5. Selecione `main` e `/ (root)` e salve.

## Importante para o ARG
O site é estático. Qualquer texto incluído no HTML/CSS/JavaScript pode ser encontrado pelo código-fonte ou pelas ferramentas do navegador. Não inclua credenciais reais nem informações privadas.
